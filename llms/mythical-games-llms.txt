# Mythical Games

> Mythical Games is a Web3 game-technology studio (an a16z portfolio company) that builds games with player-owned digital items and a secondary marketplace economy. Its Mythical Platform is a B2B toolkit that lets any game add a tradeable item-and-currency economy, exposed to integrating studios through gRPC/Protobuf SDKs (the Saga SDK and the earlier IVI SDK) rather than a public REST/OpenAPI surface. Assets can settle on the Mythos chain, a Polkadot/Substrate gaming parachain (MYTH token).

## APIs

- [Mythical Saga Platform API (gRPC/Protobuf)](https://github.com/MythicalGames/saga-sdk-proto): items, item types, currencies, currency types, listings, offers, player wallets, reservations, NFT bridge, metadata, and a server-streaming status channel.
